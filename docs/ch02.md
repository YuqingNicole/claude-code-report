## 2.2 技术栈

| 组件 | 技术选择 |
|------|---------|
| 语言 | TypeScript（严格模式）|
| 运行时 | Bun（非 Node.js）|
| 打包器 | Bun Bundler（支持编译时特性标志）|
| UI 框架 | 自定义 Ink（React for Terminal，深度重写）|
| 布局引擎 | 自研 Yoga Layout（从 C++ 移植的纯 TS 实现）|

| 认证 | OAuth 2.0 PKCE + JWT |
| 遥测 | GrowthBook + Datadog |
| 原生模块 | Rust（enigo 鼠标键盘）+ Swift（截屏/TCC 权限）|

## 2.4 模块依赖关系

```
用户输入
    ↓
entrypoints/cli.tsx
    ↓
main.tsx（协调器）
    ├── query.ts（查询循环）── QueryEngine.ts（状态管理）
    ├── tools.ts（工具装配）── tools/（54个工具）
    │       BashTool / AgentTool / FileEditTool
    │       GrepTool / WebSearch / MCPTool ...
    ├── commands.ts（命令注册表）── commands/
    ├── state/（AppState）
    └── services/
            ├── api/
            ├── mcp/
            ├── lsp/
            ├── compact/
            ├── bridge/（远程控制）
            └── coordinator/（多Agent）
```
